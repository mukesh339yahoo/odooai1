Why This Module Outperforms All Competitors

  • True Server-Side Write Protection: Unlike other modules that only hide fields cosmetically in the UI, our module blocks writes, updates, and imports at the ORM level, preventing developer mode or API tampering.
  • Confidential Data Masking: Obfuscate sensitive numbers (salaries, bank accounts, SSNs, phone numbers) with partial or full masks (e.g., **** 1234) without breaking layout.
  • Notebook Tab / Page Hiding: Hide entire tabs or pages in form views (such as Accounting, Payroll, or Internal Notes) for specific user roles.
  • Button & Action Security: Completely hide functional action buttons from unauthorized user groups to prevent unauthorized operations.
  • Excel / CSV Export Protection: Stop data leaks by stripping restricted columns from spreadsheet downloads.
  • Multi-Company Compatible: Apply rules globally or target specific companies in multi-company environments.
  • Conditional (Domain) Logic: Dynamic security based on record states (e.g., state == 'done').
  • Drag-and-Drop Priority: Manage rule priority and inheritance with sequence handles.

How to Install & Enable

1. Installation

  • Download the app and extract the ridhira_field_security folder into your Odoo addons path.
  • Restart your Odoo server instance.
  • Go to the Apps menu, click Update Apps List, and install the "Advanced Field-Level Security" module.

2. Enabling the App

  • Ensure you have activated Developer Mode in the Odoo settings.
  • Navigate to Settings > Technical > Security > Field Security Rules.
  • Click New to start creating your dynamic UI and field security rules!
